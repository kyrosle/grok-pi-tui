# 设置功能命名与中英文

用户要求：设置名称和说明用实际功能表达，去掉难理解的 V1/V2 展示名称；设置页提供中英文，默认跟随系统并允许手动切换。本增量属于 [总体 PLAN](20261003-pi-native-tui-PLAN.md) 的 T5 设置交互工作，由用户明确优先安排；不代表总体 T2–T8 完成。

## 行为

- F2 / `/settings` 的标题、分类、分组、名称、说明、选项和操作提示提供中文和英文。搜索能找到两种语言的名称、说明及原有配置键。
- 在外观设置增加语言选项：跟随系统、简体中文、English。`[ui].language` 的持久值为 `auto`、`zh-CN`、`en`，默认 `auto`；手动选择立即刷新设置页，重启保持，保存失败恢复原值。
- 自动语言优先使用有效终端 locale，macOS 在终端没有具体语言时使用系统语言。中文 locale 显示中文，其他语言回退英文；系统检测离开绘制热路径。
- 子代理团队协作、任务依赖与提醒、代码执行模式等使用功能名称；说明明确依赖、作用、即时或下次启动生效。既有 `*_v2` 键、`v1`/`v2` 等持久值和功能默认值保持兼容。
- Web 配置的 Pager 设置使用相同功能文案和持久语言配置，避免原生页与 Web 页出现两套 V2 名称。自动模式跟随运行 grok-pi 的主机系统语言，独立 Web 缺少主机信息时回退浏览器语言；明确选择保存在产品配置。
- Pi 仍负责核心配置、工具和扩展。本增量只改变设置展示和产品 UI 语言，不修改 Pi 源码、会话或认证数据。

## 验收

1. 原生设置页没有 V1/V2 作为用户功能名称；描述准确保留功能差异。
2. 两种语言都覆盖可见设置、分组子项与静态选项；技术标识、路径、模型名保持原文。
3. 单元验证 locale 优先级、旧配置默认值、语言持久化/回滚、双语搜索和 canonical 值不变。
4. Web 验证双语目录、语言设置和保存冲突保护；Rust 检查 Pi production profile 和现存 stock profile。
5. 真实原生 PTY 验证自动中文、手动英文/中文切换、重开/重启恢复、中文搜索和描述。
6. 构建并更新本机 `tpig`，保留现有配置和 `pig`，说明实际验证范围。

## 范围边界

本次翻译设置界面，不扩展为聊天内容、所有 slash 弹窗或第三方扩展内容的全应用翻译。保留原生 Pager 组件和现有设置注册、写入、错误恢复路径。
